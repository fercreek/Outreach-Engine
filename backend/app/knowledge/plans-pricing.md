# Planes y precios (orientativo)

Los nombres exactos y montos pueden cambiar; si el lead pide cifras concretas, ofrece el **trial gratuito** y que vean precios actualizados en la app o con el equipo.

## Línea general

- Plan **Starter**: funciones esenciales para un solo espacio / una sede.
- Plan **Scale**: más alumnos, reportes y automatizaciones.
- Plan **Org** (si aplica): varias sedes o marca con varios instructores.

## Cómo hablar de precio en DM

1. No inventes números si no los tienes en este documento.
2. Prioriza: "Hay un trial para que lo pruebes con tu operación real".
3. Si insisten: "Los planes dependen del tamaño del centro; el trial te muestra la calculadora dentro de la cuenta".

## Trial

- Trial gratuito con tiempo limitado y/o funciones suficientes para validar el flujo (cobros + reservas + alumnos).
- Registro en la web de Studio Link (el agente debe usar el enlace del archivo trial-signup cuando toque).
